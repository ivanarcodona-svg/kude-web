Criterios de evaluación de Análisis de datos con Python

Desarrollo de aplicaciones en lenguaje Python · Cursos de especialización · Informática y Comunicaciones · Real Decreto 566/2024

Los 4 resultados de aprendizaje y los 20 criterios de evaluación del módulo profesional Análisis de datos con Python, del título de Curso de especialización en Desarrollo de aplicaciones en lenguaje Python, según el Real Decreto 566/2024. Son los mismos en todas las comunidades.

Resultado de aprendizaje 1

Manejo, limpieza y normalización de distintos tipos de datos en función del problema a resolver.

1.aSe conocen y se importan las librerías usadas en ciencia de datos.
1.bSe ha escrito código que permite leer datos de distintos orígenes (csv, xlsx, entre otros).
1.cSe ha escrito código que permite exportar datos previamente leídos en ficheros de distinto formato (csv, xlsx, entre otros).
1.dSe ha escrito código que permite acceder a bases de datos usando librerías de ciencia de datos.
1.eSe manejan selecciones, actualizaciones, adiciones y eliminaciones de datos de una base de datos usando las librerías de Python aplicadas en ciencia de datos.
1.fSe han realizado pruebas intermedias de verificación.

Resultado de aprendizaje 2

Limpia y estandariza lotes de datos de forma lógica y eficiente para su tratamiento posterior de acuerdo al problema a resolver.

2.aSe han analizado los datos leídos.
2.bSe han deducido las operaciones para normalizar y estandarizar datos en Python.
2.cSe ha escrito código que permite limpiar y estandarizar datos basándose en el problema que hay que resolver.
2.dSe han aplicado intervalos en series de datos para realizar agrupaciones de forma coherente.
2.eSe han identificado los datos a convertir de categóricos a numéricos.
2.fSe ha escrito código que modifica variables categóricas en variables cuantitativas en Python.

Resultado de aprendizaje 3

Realiza análisis exploratorios en datos teniendo en función del alcance del problema a resolver.

3.aSe ha resumido grandes cantidades de datos para toma decisiones.
3.bSe ha sido capaz de responder preguntas relevantes relativos a los datos.
3.cSe han reconocido patrones en los datos.
3.dSe ha escrito código en Python que permita conocer la correlación entre variables.

Resultado de aprendizaje 4

Desarrolla modelos en lenguaje Python dando solución al problema planteado.

4.aSe ha analizado la relación entre una variable continua y una o más variables independientes mediante el ajuste de una ecuación lineal.
4.bSe ha modelado una relación no lineal entre variables independientes y dependientes.
4.cSe ha determinado correctamente la muestra en la que se ensayará el procedimiento a evaluar.
4.dSe ha realizado una predicción y se ha comprobado su precisión y validez usando una muestra de datos válida.
